# Hugo Pinta - Personal Website & Portfolio

Tämä on Hugo Pintan moderni portfoliosivusto, joka on toteutettu **AI-First** -kehitysperiaatteilla käyttäen tekoälyagenttia ja moderneja kehitystyökaluja.

## Ominaisuudet
- 🌙 Tumma / vaalea tila (Dark/Light mode)
- ⚡️ Kevyt, responsiivinen ja nopea (puhdas HTML5, CSS3 ja JavaScript)
- 💻 Interaktiivinen terminaaliefekti
- 🚀 Suora GitHub Pages -tuki

## Käynnistys paikallisesti
Voit avata sivuston suoraan selaimessasi:
```bash
open index.html
```
tai käynnistää pienen paikallisen kehityspalvelimen:
```bash
npx serve .
```
